Delete a file and mean it.

YFP overwrites a drive's free space so tools like PhotoRec or DiskDrill have nothing left to reconstruct from a "deleted" file. Fully offline, zero telemetry, open source on both platforms.

Download How it actually works
The problem

"Deleted" almost never means gone.

Deleting a file typically just removes its filesystem entry — the underlying data stays on disk, recoverable with free consumer tools, until something else happens to overwrite those same sectors.

The solution

Close that window on purpose.

YFP deliberately writes new data across a drive's free space. Once complete, the sectors a deleted file used to occupy contain different data — leaving common recovery tools with nothing to reconstruct.

Trust & verification

Security architecture

A factual account of what this software does, how, and what it deliberately does not claim.

User-selected target → local overwrite engine → free space overwritten on-device All processing happens locally. No data — not even metadata about the operation — ever leaves the device.

On-device processing

All overwrite operations execute entirely within the local filesystem. No cloud component, no remote server.

Overwrite patterns

Supports zero-fill and pseudo-random patterns. Pattern generation uses a fast, non-cryptographic algorithm by design.

Compliance & scope of claims

YFP defeats common consumer recovery tools. It does not assert compliance with forensic standards such as DoD 5220.22-M or NIST SP 800-88. On flash storage (SSDs, most phones), wear-leveling means the physical cells backing a logical sector aren't deterministic — a limitation shared by every consumer-grade free-space tool, not unique to this one. For regulated data destruction, consult a certified sanitization solution.

FAQ

Does YFP delete or scan my personal files?

No. It never reads or touches existing files — only writes temporary dummy files into free space, then deletes them when finished or cancelled.

Will this stop all data recovery, forever?

It defeats common consumer recovery tools. Not a forensic-grade guarantee — see Security for the full account, particularly on flash storage.

Why does it need so much free space temporarily?

By design — filling free space with new data is the mechanism that overwrites where deleted files used to sit. A safety floor always keeps a minimum free.

Is there a paid version?

No. Free and open source, no paid tier, no ads, no in-app purchases.

Awareness

Free-space overwriting is a widely-used, legitimate privacy practice. Use it as routine digital hygiene when disposing of or repurposing a device — not as a substitute for full-disk encryption on devices still in active use.

Security

Things worth knowing before you rely on this

Malware scanning vs. zero-knowledge is a real tension

The hash-lookup path leaks nothing but a SHA-256 digest. Full-scan is opt-in and explicitly breaks zero-knowledge for that one file.

Browser memory can't be securely wiped

Non-extractable keys plus prompt dereferencing is the practical best-effort, not a guarantee against local memory-inspection access.
